# 可调用对象的包装器和绑定器

## 函数分类（可调用对象）

* 普通函数
* 类的静态成员函数
* 仿函数
* lambda 函数

* 类的非静态成员函数 

### 1. 普通函数

**概念：**
这是最基础的函数形式，定义在全局作用域或命名空间内，不属于任何类。它们是 C 语言风格的函数。

**特点：**
*   **无状态**：函数本身不能保存状态（除非使用静态局部变量或全局变量，但不推荐）。
*   **简单**：直接通过函数名调用。
*   **指针**：函数名即为函数指针。

**代码样例：**

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

// 定义一个普通函数
void printNum(int n) {
    std::cout << "普通函数: " << n << std::endl;
}

int add(int a, int b) {
    return a + b;
}

int main() {
    // 1. 直接调用
    printNum(10);

    // 2. 通过函数指针调用
    void (*funcPtr)(int) = printNum;
    funcPtr(20);

    // 3. 作为参数传递给 STL 算法
    std::vector<int> v = {1, 2, 3};
    std::for_each(v.begin(), v.end(), printNum);

    return 0;
}
```

### 2. 类的静态成员函数 (Static Member Functions)

**概念：**
只是定义在类内部，但前面加了 `static` 关键字。

使用的时候加个类名和作用域，其他与普通函数无其他区别

**特点：**
*   **不属于对象**：它属于类本身，不依赖类的实例（对象）存在。
*   **无 `this` 指针**：因为它不绑定到具体对象，所以不能直接访问类的**非静态**成员变量。
*   **类似全局函数**：在底层实现上，它和普通函数几乎一样，只是作用域被限制在类里面了（起到了命名空间的作用）。

**代码样例：**

```cpp
#include <iostream>

class MathUtils {
public:
    // 静态成员函数
    static int multiply(int a, int b) {
        return a * b;
    }
    
    // 静态成员变量
    static int baseValue;
};

int MathUtils::baseValue = 10;

int main() {
    // 1. 直接通过 类名::函数名 调用 (无需创建对象)
    int result = MathUtils::multiply(5, 4);
    std::cout << "静态成员函数结果: " << result << std::endl;

    // 2. 也可以通过对象调用（不推荐，容易误导）
    MathUtils obj;
    std::cout << "通过对象调用: " << obj.multiply(2, 3) << std::endl;
    
    // 3. 函数指针类型 (注意没有类成员指针的特殊语法)
    int (*ptr)(int, int) = &MathUtils::multiply;
    std::cout << "通过指针调用: " << ptr(10, 10) << std::endl;

    return 0;
}
```

### 3. 仿函数 (Functors / Function Objects)

**概念：**
仿函数本质上是一个**类（或结构体）**，但它重载了 `operator()`（函数调用运算符）。这使得该类的对象可以像函数一样被调用。

**特点：**
*   **有状态**：这是仿函数最大的优势。它可以通过成员变量保存状态（例如：累加器、配置参数等）。
*   **灵活性**：可以拥有构造函数、析构函数，可以在调用之间保持数据。
*   **内联优化**：编译器通常能更好地内联仿函数调用，性能通常优于函数指针。

**代码样例：**

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

// 定义一个仿函数类
class Accumulator {
private:
    int total; // 内部状态
public:
    Accumulator() : total(0) {}

    // 重载 () 运算符
    void operator()(int i) {
        total += i;
        std::cout << "当前累加: " << i << ", 总和: " << total << std::endl;
    }

    int getTotal() const { return total; }
};

int main() {
    Accumulator acc;

    // 像调用函数一样调用对象
    acc(10); 
    acc(20);

    std::cout << "最终结果: " << acc.getTotal() << std::endl;

    // 在 STL 中使用
    std::vector<int> nums = {1, 2, 3, 4};
    // 注意：std::for_each 传值返回，所以要捕获返回值才能看到改变的状态
    acc = std::for_each(nums.begin(), nums.end(), acc); 
    std::cout << "STL 遍历后的总和: " << acc.getTotal() << std::endl;

    return 0;
}
```

### 4. Lambda 函数 (Lambda Expressions)

**概念：**
C++11 引入的特性，它本质上是**匿名仿函数**的语法糖。它允许你在需要的地方就地定义短小的函数对象。

**语法：**
`[捕获列表](参数列表) -> 返回类型 { 函数体 }`

**特点：**
*   **便捷**：无需单独定义函数或类，随用随写。
*   **捕获上下文**：可以捕获外部作用域的变量（通过 `[` `]`）。
    *   `[=]`：按值捕获所有外部变量。
    *   `[&]`：按引用捕获所有外部变量。
    *   `[x]`：只捕获变量 x。

**代码样例：**

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    int threshold = 5; // 外部变量

    std::vector<int> nums = {1, 10, 3, 8, 2, 6};

    // Lambda 表达式
    // [threshold]: 捕获外部变量 threshold
    // (int n): 参数
    auto printIfLarge = [threshold](int n) {
        if (n > threshold) {
            std::cout << "Lambda 筛选: " << n << " (大于 " << threshold << ")" << std::endl;
        }
    };

    std::for_each(nums.begin(), nums.end(), printIfLarge);

    // 另一个例子：修改外部变量（需用引用捕获 [&]）
    int count = 0;
    std::for_each(nums.begin(), nums.end(), [&](int n){
        if(n % 2 == 0) count++;
    });
    std::cout << "偶数个数: " << count << std::endl;

    return 0;
}
```

### 5. 类的非静态成员函数 (Non-static Member Functions)

**它定义与众不同，但又是最常用的，所以才有了包装器与绑定器去统一它**

**概念：**
普通的类成员函数。最关键的是，它们都有一个隐藏的参数：**`this` 指针**。

**特点：**
*   **依赖对象**：必须基于一个具体的对象实例才能调用。
*   **复杂的指针语法**：函数指针类型必须包含类名，例如 `void (MyClass::*)(int)`。
*   **不能直接作为回调**：因为标准的 C 风格回调或 STL 算法通常不接受这种自带隐藏参数的函数。通常需要结合 `std::bind`、`std::mem_fn` 或 Lambda 来适配。

**代码样例：**

```cpp
#include <iostream>
#include <functional> // 为了使用 std::bind 和 std::function

class Printer {
public:
    void printMessage(const std::string& msg) {
        std::cout << "Printer 类成员函数: " << msg << std::endl;
    }
};

int main() {
    Printer p;

    // 1. 普通调用
    p.printMessage("Hello");

    // 2. 成员函数指针定义与调用 (非常麻烦，很少直接这样用)
    void (Printer::*funcPtr)(const std::string&) = &Printer::printMessage;
    (p.*funcPtr)("通过指针调用"); // 必须绑定到对象 p 上

    // 3. 使用 std::function 和 std::bind (现代 C++ 常用做法)
    // std::bind 将 p 绑定为第一个参数 (即 this)
    std::function<void(std::string)> f = std::bind(&Printer::printMessage, &p, std::placeholders::_1);
    f("Bind 调用");

    // 4. 使用 Lambda 包装 (最推荐的现代做法)
    auto lambdaCall = [&](const std::string& s) {
        p.printMessage(s);
    };
    lambdaCall("Lambda 包装成员函数");

    return 0;
}
```

### 总结对比

| 类型               | 关键字/语法             | 是否有 `this` 指针  | 能否存状态        | 典型用途                         |
| :----------------- | :---------------------- | :------------------ | :---------------- | :------------------------------- |
| **普通函数**       | `void func() {}`        | 无                  | 否                | 通用逻辑，无状态操作             |
| **静态成员函数**   | `static void func() {}` | 无                  | 否                | 工厂方法，属于类的工具函数       |
| **仿函数**         | `class { operator() }`  | 有 (仿函数自身的)   | **能**            | 复杂算法策略，需要保持状态的场景 |
| **Lambda**         | `[]() {}`               | 有 (闭包对象自身的) | **能** (通过捕获) | 临时的、短小的回调，STL 算法参数 |
| **非静态成员函数** | `void func() {}`        | **有** (隐式参数)   | 能 (访问对象成员) | 描述对象的行为                   |

**在现代 C++ 开发中的建议：**

1.  如果逻辑很简单且不需要复用，首选 **Lambda**。
2.  如果逻辑复杂、需要跨多个函数复用且需要保存状态，使用 **仿函数**。
3.  如果只是作为回调接口（如 GUI 按钮点击），通常使用 **Lambda 包装非静态成员函数**。
4.  纯粹的数学计算或工具方法，使用 **静态成员函数** 或 **普通函数**。



## 可调用对象的包装器 function

`std::function` 是 C++11 标准库中引入的一个非常重要的类模板，位于 `<functional>` 头文件中,它是**可调用对象的通用多态包装器**，用简单的、统一的方式处理可调用对象

在 `std::function` 出现之前，如果想把不同类型的东西存在同一个容器里，或者作为参数传递给同一个函数，非常困难，因为它们的类型各不相同。

`std::function` 将它们统一成了同一个类型。

* 基本语法：

```cpp
#include <functional>

// std::function<返回值类型(参数列表)>
std::function<void(int, double)> func;
```

* 应用：

```cpp
#include <iostream>
#include <string>     // 必须包含 string
#include <functional> // 必须包含 functional 用于 std::function

using namespace std;  // 使用标准命名空间

// 1. 普通函数
void show(int bh, const string& message)
{
    cout << "普通函数: " << bh << ":" << message << endl;
}

// 2. 类中静态成员函数
struct AA
{
    static void show(int bh, const string& message)
    {
        cout << "静态成员函数: " << bh << ":" << message << endl;
    }
};

// 3. 仿函数（函数对象）
struct BB
{
    void operator()(int bh, const string& message)
    {
        cout << "仿函数: " << bh << ":" << message << endl;
    }
};

// 4. 类中普通成员函数
struct CC
{
    void show(int bh, const string& message)
    {
        cout << "成员函数: " << bh << ":" << message << endl;
    }
};

// 5. 可以被转换为普通函数指针的类
struct DD
{
    using Fun = void(*)(int, const string&);
    operator Fun()
    {
        return show; // 返回全局函数 show
    }
};

int main()
{
    // ==========================================
    // 1. 普通函数
    // ==========================================
    // 方式一：用函数指针
    void(*fp1)(int, const string&) = show;
    fp1(1, "aaa");

    // 方式二：用 std::function
    function<void(int, const string&)> fn1 = show;
    fn1(1, "aaa");

    // ==========================================
    // 2. 类的静态成员函数
    // ==========================================
    // 静态成员函数没有 this 指针，用法和普通函数一样
    void(*fp3)(int, const string&) = AA::show;
    fp3(2, "static ptr"); 

    function<void(int, const string&)> fn3 = AA::show;
    fn3(2, "static func"); 

    // ==========================================
    // 3. 仿函数
    // ==========================================
    BB bb;
    bb(3, "functor call");

    function<void(int, const string&)> fn4 = BB();
    fn4(3, "functor func"); 

    // ==========================================
    // 4. Lambda 表达式
    // ==========================================
    auto lb = [](int bh, const string& message)
    {
        cout << "Lambda: " << bh << ":" << message << endl;
    }; // 这里必须加分号

    lb(4, "lambda call");

    function<void(int, const string&)> fn5 = lb;
    fn5(4, "lambda func");

    // ==========================================
    // 5. 类的非静态成员函数 (重点难点)
    // ==========================================
    CC cc;

    // 方式一：成员函数指针
    // 语法：Ret(Class::*ptr)(Args) = &Class::func;
    void (CC::*fp11)(int, const string&) = &CC::show;
    (cc.*fp11)(5, "member ptr"); // 必须通过对象调用

    // 方式二：std::function
    // 【修正】非静态成员函数隐含第一个参数是 this 指针 (即类的实例)
    // 所以 function 的模板参数必须包含类对象： function<void(CC&, int, const string&)>
    function<void(CC&, int, const string&)> fn11 = &CC::show;
    
    // 调用时，第一个参数传入对象实例 cc
    fn11(cc, 5, "member func");

    return 0;
}
```



## 适配器 bind

`std::bind()`模板函数是一个通用的函数适配器，它用一个可调用对象及其参数，生成一个新的可调用对象，以适应模板
(为了适用模板，把一个函数对象改头换面，变成一个新的函数对象)

包含头文件：`#include<functional>`

具体使用如下：
```cpp
#include <iostream>
#include <string>
#include <functional> // 必须包含：function 和 bind

using namespace std;
using namespace std::placeholders; // 必须包含：_1, _2 等占位符

// ==========================================
// 1. 普通全局函数
// ==========================================
void show(int bh, const string& message)
{
    cout << "普通函数: bh=" << bh << ", msg=" << message << endl;
}

// ==========================================
// 2. 类中静态成员函数
// ==========================================
struct AA
{
    static void show(int bh, const string& message)
    {
        cout << "静态成员函数: bh=" << bh << ", msg=" << message << endl;
    }
};

// ==========================================
// 3. 仿函数（函数对象）
// ==========================================
struct BB
{
    void operator()(int bh, const string& message)
    {
        cout << "仿函数: bh=" << bh << ", msg=" << message << endl;
    }
};

// ==========================================
// 4. 类中普通成员函数 (重点)
// ==========================================
struct CC
{
    void show(int bh, const string& message)
    {
        cout << "成员函数: bh=" << bh << ", msg=" << message << endl;
    }
};

// ==========================================
// 5. 可转换为函数指针的类
// ==========================================
struct DD
{
    using Fun = void(*)(int, const string&);
    operator Fun()
    {
        return show; // 返回全局函数 show
    }
};

int main()
{
    // ==========================================
    // 一、普通函数与 bind 的基础用法
    // ==========================================
    cout << "--- 1. 普通函数 bind 适配 ---" << endl;
    
    // 1. 标准绑定：参数一一对应
    // 签名保持一致：void(int, string)
    function<void(int, const string&)> fn1 = bind(show, _1, _2);
    fn1(1, "标准绑定");

    // 2. 调换参数顺序 (适配器模式)
    // 场景：模板或接口要求参数顺序是 (string, int)，但我们的实现是 (int, string)
    // 调用 fn2("msg", 2) -> _1="msg", _2=2 -> 传给 show(_2, _1) 即 show(2, "msg")
    function<void(const string&, int)> fn2 = bind(show, _2, _1);
    fn2("调换顺序", 2);

    // 3. 减少参数 / 提前绑定参数
    // 场景：接口只允许传一个 string，但 show 需要 int。我们将 int 固定为 100
    // 注意：这里的 100 是值传递。若需引用传递请用 std::ref
    function<void(const string&)> fn3 = bind(show, 100, _1);
    fn3("减少参数"); 

    // 4. 忽略多余参数
    // 场景：接口会给3个参数，但我们只用前2个
    // _3 虽然传进来了，但没有被 bind 转发给 show
    function<void(int, const string&, int)> fn4 = bind(show, _1, _2);
    fn4(1, "忽略参数", 999);


    // ==========================================
    // 二、各种可调用对象的 bind 统一化
    // ==========================================
    cout << "\n--- 2. 各类对象 bind 演示 ---" << endl;

    // 1. 静态成员函数 (AA)
    // 静态成员没有 this 指针，bind 写法与普通函数完全一样
    function<void(int, const string&)> fn_static = bind(AA::show, _1, _2);
    fn_static(10, "静态成员");

    // 2. 仿函数 (BB)
    BB bb;
    // 仿函数对象 bb 本身就是可调用的，直接 bind 对象实例
    function<void(int, const string&)> fn_functor = bind(bb, _1, _2);
    fn_functor(20, "仿函数");

    // 3. Lambda 表达式
    auto lb = [](int bh, const string& message) {
        cout << "Lambda: bh=" << bh << ", msg=" << message << endl;
    };
    function<void(int, const string&)> fn_lambda = bind(lb, _1, _2);
    fn_lambda(30, "Lambda");


    // ==========================================
    // 三、非静态成员函数的难题与解决 (重点)
    // ==========================================
    cout << "\n--- 3. 解决成员函数多余参数问题 ---" << endl;
    CC cc;

    // 【问题痛点】：
    // 成员函数 CC::show 的实际签名是：void(CC* this, int, string)
    // 如果直接用 function 包装，必须显式声明类的类型，调用时也必须传对象
    function<void(CC&, int, const string&)> fn_raw = &CC::show;
    fn_raw(cc, 40, "原始调用(麻烦)"); 
    // ^^^ 这种写法无法放入只接受 void(int, string) 的通用模板中

    // 【解决方案】：使用 bind 提前绑定对象
    // 将 &cc 绑定到隐含的第一个参数(this) 上
    // 此时生成的 fn_bound 只剩下两个参数 (int, string)，完美适配通用接口
    function<void(int, const string&)> fn_bound = bind(&CC::show, &cc, _1, _2);
    
    // 调用时不再需要传递 cc 对象
    fn_bound(50, "Bind解决成员适配");

    return 0;
}


/* 补充：
bind() 返回的是 function模板类的对象，其中，function<void(int,const string&)> 可以替换为 auto,即：
auto = bind(&CC::show, &cc, _1, _2);


```

综合以上内容，我们实现了最终目的，通过一个模板把6种可调用对象的代码统一了



## 应用样例

`thread`类的构造函数很强大，可以接受任意可调用对象，可调用对象的参数也是任意变化的，这是如何实现的？如何用包装器和绑定器写出来？

```cpp
#include <iostream>
#include <string>
#include <thread>
#include <functional>

using namespace std;

// 测试函数1：无参
void show0() {
    cout << "  执行 show0: 打印 1" << endl;
}

// 测试函数2：带参数
void show1(int a, const string& b) {
    cout << "  执行 show1: a=" << a << ", b=" << b << endl;
}

// 模板函数
/*  基础版本，只能无法实现右值传递
template<typename Fn,typename... Args>
void show(Fn fn,Args... args)
{
        cout<<"start"<<endl;
        
        auto f = bind(fn,args...);
        f();
 
        cout<<"end"<<endl;
}
*/
// Fn&& 和 Args&&... 是“万能引用”，既能接左值也能接右值
template<typename Fn, typename... Args>
void show(Fn&& fn, Args&&... args)
{
    cout << "start" << endl;

    // 1. 使用 bind 将函数和参数打包成一个可调用对象 f
    // std::forward 保证参数的原有属性（左值还是右值）传递给 bind
    auto f = bind(std::forward<Fn>(fn), std::forward<Args>(args)...);

    // 2. 执行可调用对象
    f();

    cout << "end" << endl;
}

int main()
{
    // 测试1：无参函数
    show(show0);

    // 测试2：带参函数
    // bind 会把 10 和 "hello" 绑定进 f 中
    show(show1, 10, "hello");

    return 0;
}
```





## 回调函数的实现

```cpp
#include <iostream>
#include <string>
#include <functional> // 必须包含

using namespace std;

// 使用 std::function 定义回调类型，更直观
using Callback = function<void(const string&)>;

class Downloader {
public:
    // 接受一个回调对象
    void start(const string& url, Callback cb) {
        cout << "开始任务: " << url << endl;
        
        // 模拟工作结束，触发回调
        if (cb) {
            cb("下载成功");
        }
    }
};

class Client {
public:
    void onComplete(const string& msg) {
        cout << "[Client类成员回调]收到通知: " << msg << endl;
    }
};

int main() {
    Downloader dl;
    Client client;

    // 场景 1：使用 Lambda (最常用，代码内聚)
    dl.start("http://movie.mp4", [](const string& msg) {
        cout << "[Lambda回调] " << msg << endl;
    });

    // 场景 2：使用类的成员函数 (配合 bind)
    // 这里解决了你之前遇到的“成员函数多一个 this 参数”的问题
    dl.start("http://image.jpg", bind(&Client::onComplete, &client, placeholders::_1));

    return 0;
}
```
